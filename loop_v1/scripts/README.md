# scripts — 原神确定性负载

## `workload_spin_touch_v1.json` — 当前默认

触控拖拽转视角: `(900,400) → (2000,400)` 匀速 12 秒, 连做 3 次。

- **不按 A 键**。原神里 A 是交互/确认, 身边有可交互物就会开箱子或触发对话,
  直接毁掉可重复性 (前人的 `scenario_fixed_spot_v1.json` 每轮按 4 次 A)。
- **不推左摇杆 / 不走位**, 人物位置由构造保证不变。
- **不从屏幕中心拖**: 中心点会打开派蒙菜单。y=400 在中心线上方, x 横跨中心但不经过中心点。
- **不按 BACK**。要收通知栏用 `cmd statusbar collapse`。

## `workload_spin_v1.json` — 手柄版, **原神 7.1.0 起已失效**

原神更新到 7.1.0 之后手柄注入不再被游戏接受: 脚本照常跑完、退出码正常, 但**视角根本不转**,
采到的是静止画面。这种失效是安静的 —— 帧时序照样有数, 只是那份数不是转视角的负载。

**所以 7.1.0 之后用这个文件跑出来的原神数据一律作废。** 文件保留供回溯历史证据
(2026-09-23 之前的 `runs/` 全部基于它), 不要再用它开新实验。

`auto/autoloop.py` 在跑基线之前会自动核一次「视角真的在转」(判据在 `src/framecheck.rs`),
就是为了不让这种安静失效再混进数据。
